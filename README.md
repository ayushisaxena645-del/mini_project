# Team 21 - Multimodal AI Phishing Detection Engine

## Project Objective
To build a prototype that identifies suspicious URLs,
phishing messages, and potentially deceptive screenshots.

## Technology Stack
- Python
- Flask
- HTML
- CSS
- JavaScript

## Team

- Priyal: URL and text analysis
- Aishi: Screenshot, brand, and form analysis

## Project Status

## Run Locally
Install the dependency with `pip install -r requirements.txt`, then start the app with `python app.py`.
Open [http://127.0.0.1:5001](http://127.0.0.1:5001) to view this project.
